## バージョン情報

### プロモーション用テキスト（170文字以内・審査なしでいつでも変更可）

杉並区「すぎなみアートウォーク」（2027年3月21日まで）のアートサイン7か所を、地図・スタンプ・歩いた記録で楽しく巡れる非公式アプリです。

### 概要（説明文）

杉並区で開催中の「すぎなみアートウォーク」を、もっと楽しむための非公式アプリです。

阿佐谷・高円寺の公園などに設置された7か所のアートサインを、地図を見ながら好きな順番で巡れます。見た作品の記録や記念の写真、歩いた距離まで、ひとつのアプリに残せます。

■ 主な機能

・地図と一周ルートの例
7か所のアートサインと、ぐるっと一周する徒歩ルートの例を地図に表示します。

・近づくとお知らせ（ホット＆コールド）
いちばん近いアートサインに近づくほど「もうすぐ！」と表示が変わります。

・「見た！」の記録とスタンプ帳
作品を見たら記録すると、場所ごとのオリジナルスタンプが押されます。そのまま記念の写真も撮れます。

・歩いた記録
「スタート」から歩いた道のりを地図に残し、距離・歩数・消費カロリーの目安を表示します。一時停止もできます。

・称号とすぎなみ座
条件を満たすと称号がもらえます。7か所すべて巡ると、巡った順に星がつながる「すぎなみ座」が完成します。

・ノベルティ配布場所
アート作品を使ったオリジナルノベルティを配っている商店街のお店を、地図と一覧で確認できます。

・楽しみ方ガイド
はじめての方にも分かりやすいガイド付きです。

■ ご利用にあたって

・本アプリは、杉並区とは関係のない、個人が開発した非公式アプリです。イベントについてのお問い合わせは杉並区の公式ページをご確認ください。アプリについてのお問い合わせを区へ送るのはご遠慮ください。
・健康ポイントは、アートサインの二次元コードを杉並区の健幸アプリで読み取ると貯まります。本アプリの記録はポイントの対象外です。
・ノベルティの情報は区の公式サイトをもとに本アプリが独自にまとめたもので、最新の状況と異なる場合があります。
・記録や写真は、お使いのiPhoneの中にだけ保存されます。
・歩きスマホはせず、周囲に気をつけてお楽しみください。
・「スタート」で記録している間は、画面を消していても位置情報を使用します。

### メモ（審査担当向け・英語）

This is an unofficial companion app, made by an individual developer living in Suginami City, for the public art walk event "Suginami Art Walk" (October 1, 2026 – March 21, 2027) held by Suginami City, Tokyo. The app is not affiliated with or endorsed by Suginami City. This is stated in the app name, the description, the in-app guide, and the Info tab. The app does not use the city's logos, mascot or artwork images.

Event information comes from the city's official public pages:
https://www.city.suginami.tokyo.jp/s092/event/27274.html

How to review without visiting the location:
- Open the "アート" (Art) tab, choose any sign, and tap "見た！を記録する" (Record as seen). When you are far from the sign, the app asks for confirmation, and you can record it manually. A stamp is added to the stamp book. Recording all 7 signs shows the completion screen.
- The location can be simulated (for example 35.70447, 139.63642, Asagaya Station South Exit).

Location usage:
- "When In Use" location is used to show nearby signs and the distance to them.
- Background location (UIBackgroundModes: location) is used only while the user explicitly records a walk with the "スタート" (Start) button. It stops when the user pauses or stops recording. The blue location indicator is shown while recording. No "Always" permission is requested.
- Motion & Fitness is used only to show step counts for a recorded walk.

All records and photos are stored only on the device. The app downloads a small public JSON file (novelty distribution spots and notices) from GitHub Pages. It does not send any user data.
