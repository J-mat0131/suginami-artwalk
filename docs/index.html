すぎなみアートウォークアプリ(非公式)

App Storeからダウンロード iPhone（iOS 17以降）・無料

阿佐谷・高円寺の公園などに、女子美術大学の学生さんが描いたアートサインが7か所。杉並区の「すぎなみアートウォーク」を、地図を見ながら気軽に巡れたらいいなと思い、iPhoneアプリを作りました。

アートサインの場所の確認や、見た作品の記録、記念の写真、歩いた距離まで、ひとつのアプリで残せます。お散歩のおともに使って、まち歩きとアートをもっと楽しんでもらえたらうれしいです。

杉並区在住の個人開発者より

アプリでできること

map

地図と一周ルートの例

7か所のアートサインと、ぐるっと一周する徒歩ルートの例を地図に表示。巡る順番は自由です。

near_me

近づくとお知らせ

アートサインの近くに来ると知らせてくれるので、見逃しません。

photo_camera

「見た！」と記念写真

作品を見たら記録して、そのまま記念の写真も。あとからアルバムで見返せます。

directions_walk

歩いた記録

「スタート」から歩いた道のりを地図に残し、距離・歩数・消費カロリーの目安を表示。一時停止もできます。

redeem

ノベルティ配布場所

オリジナルノベルティを配っている商店街のお店を地図で確認。配布時間・休みも見られます。

military_tech

7か所コンプリート

すべて巡ると、記念写真と歩いた記録が並ぶコンプリート画面が待っています。

ご利用の前に

  • このアプリは、杉並区とは関係のない非公式アプリです。アプリについてのお問い合わせを区へ送るのはご遠慮ください。
  • 健康ポイントは、アートサインの二次元コードを区の健幸アプリ「なみチャレ」で読み取ると貯まります。このアプリの記録はポイントの対象外です。
  • 歩きスマホはせず、住宅街では静かに。アートサインには触れないようにしましょう。
  • 記録や写真はお使いのiPhoneの中にだけ保存されます。
