# すぎなみアートウォークアプリ(非公式)

杉並区「すぎなみアートウォーク」（2026/10/1〜2027/3/21）の7か所のアートサインを巡るための非公式SwiftUIアプリです。

## 機能

- **マップ**: 7か所のピン（阿佐谷=緑／高円寺=紺）と、阿佐ケ谷駅から一周する徒歩ルート（MapKitで計算、取れない区間は点線）。一周の距離と所要時間を表示
- **次の目的地**: 未訪問の次のサインまでの距離を下部に表示。60m以内に近づくと「近くにアートサインがあります」に切り替わる
- **見た！記録**: 現地では1タップで記録、離れている場合は確認ダイアログ付きで手動記録。7か所達成で完了画面
- **作品ページ**: タイトル・作者・コンセプト要旨・「現地で探してみよう」ポイント、Appleマップで徒歩経路、区公式ページへのリンク、共有
- **案内**: 期間・公式PDF（推奨コースマップ／ノベルティ配布場所）・なみチャレのポイント・マナー・問い合わせ先
- 記録と位置情報は端末内のみ。サーバー・外部SDKなし

## ビルド手順

必要: Xcode 15以上、iOS 17以上

```sh
brew install xcodegen
cd SuginamiArtWalk
xcodegen generate
open SuginamiArtWalk.xcodeproj
```

XcodeGenを使わない場合は、Xcodeで新規「iOS App（SwiftUI）」を作り、`SuginamiArtWalk/` 以下のSwiftファイルを追加し、Info.plistに `NSLocationWhenInUseUsageDescription` を設定してください。

シミュレータで到着判定を試すには、Features → Location → Custom Location に下記の座標を入力します（例: 阿佐ケ谷駅南口 `35.704478, 139.636427`）。

## 構成

```
SuginamiArtWalk/
  App/SuginamiArtWalkApp.swift   エントリ、テーマ、タブ
  Models/ArtSign.swift           7か所のデータとイベント情報
  Services/ProgressStore.swift   鑑賞記録（UserDefaults）
  Services/LocationService.swift 現在地・距離・到着判定
  Services/RouteService.swift    MapKit徒歩ルート
  Views/MapScreen.swift          地図・ピン・進捗リング
  Views/SignListView.swift       一覧
  Views/SignDetailView.swift     作品詳細・記録・完了画面
  Views/InfoView.swift           案内・公式リンク
```

## 公開する場合の注意

- **非公式であることを明示**: アプリ名・説明文に「非公式」を入れ、区のロゴや「なみすけ」の画像は使わないこと（区の公式キャラクター）
- **作品画像**: 区は作品画像を公開していません。現地で撮った写真を載せる場合も、作品の著作権は作者にあるため、事前に区・作者の許諾を取るのが安全です
- **なみチャレとの関係**: 本アプリの記録は健康ポイントの対象外。二次元コードの読み取りは「なみチャレ」で行う旨を表示済み
- **App Store審査**: 自治体名を含むアプリは「公式と誤認させない」ことが求められます。審査メモに非公式である旨と情報源URLを書いておくとスムーズです
- 期間終了（2027/3/21）後は開催期間外の表示が出ます。サインは台風等で一時撤去される場合があります
